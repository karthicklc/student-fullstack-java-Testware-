Q9) CODE:
	try {
await axios.get("http://localhost:8080/api/students/99");
console.log("OK");
} catch (err) {
console.log(err.response.status);
console.log(err.response.data.error);
}
console.log("Done");

OUTPUT:	500
	Internal Server Error
	Done

REASON:	Axios receives an HTTP 500 Internal Server Error from the Spring Boot backend for student ID 99, so execution enters the catch block, prints 500 and Internal Server Error, and then prints Done because the error is handled.
